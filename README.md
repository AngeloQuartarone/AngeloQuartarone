# 👋 Hi, I'm Angelo Quartarone

**Backend & systems-minded engineer** — Computer Science graduate, University of Pisa.
I build from the metal up: roots in **C and low-level efficiency**, focus on **scalable backends**
and **polished apps across mobile, desktop and the browser**.

### 🧭 What I'm about
- **Backend engineering** — APIs, databases and scalability, mostly in **Python**.
- **Apps that ship** — **Android** (Kotlin + Jetpack Compose, Clean Architecture), **macOS** (Swift), **browser extensions** (Manifest V3 + AI).
- **Engineering first** — I lean on a C/systems background to write fast, deliberate code in any language, and I'm not afraid to reverse-engineer undocumented hardware when a project calls for it.
- **Pragmatic with AI** — I build fast with AI-assisted workflows, but I own the architecture and the hard decisions.

Also fluent in **TypeScript**, **Bash**, **SQL**, and functional languages like **OCaml**.
